# Fixing Vertec With AI

Bare-minimum source for the Reveal.js presentation.

The pushed repo contains the deck, the assets it actually uses, the local Vertec
fixture, and the v1 helper used in the embedded demo. The workshop notes,
research, later prototypes, QA output, and full asset library stay local under
`.work/presentation-cleanup/` so they can keep feeding future edits without
going to GitHub Pages.

## run it locally

```sh
npm install
npm run dev
```

Open the local URL printed by Vite, usually <http://127.0.0.1:5173>.

## build it

```sh
npm run check
```

The live deck is published at
<https://hrussellzfac023.github.io/fixing-vertec-with-ai/>.
