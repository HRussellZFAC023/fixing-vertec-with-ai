Fixing Vertec With AI

Can we do better?

Henry Russell

Timing: 2 minutes. Open with the groan everyone in the room already feels, then refuse the cheap shot. The joke is not that people hate admin. The joke is that a serious company pays clever, expensive people to act as copy, paste, memory, policy engine, and QA for a grid of tiny boxes, every Friday, forever. Vertec is the running example. The real subject is fixing any annoying tool with AI without switching your brain off.

Hidden policy

Timing: 2 minutes. "Fill 8 hours" is not enough. Some projects want specific service Text. Some people backfill the whole month. Holidays and absences change the answer. This is why the first useful AI move is to clarify and critique, not to click Submit faster.

UI audit

Vertec does not follow Jakob's law.

Timing: 3 minutes. Jakob's law: people expect your site to work like the other sites they already know. Vertec did not get the memo. This is the empathy map in visual form. Pick five callouts, not all thirteen: no clear page structure, manual navigation, icon only controls, not a real table, fill everything by hand. Then bridge: the same problems hurt humans, keyboard users, screen readers, and AI agents.

Cybernetic Delivery

A feedback system, not a tool rollout.

The CDM lens, small enough for this room: make the work visible, shorten the feedback loop, measure the system, and keep humans accountable for judgement.

Watch it grind.

The trick that works on any site

Save the page. Ask AI. Get a script.


// paste straight into the DevTools console
document.querySelectorAll('.vt-row')
  .forEach(r => r.style.outline = '2px solid #0099CC');
The reusable method
  • Capture: save the page as HTML or a web archive.
  • Ask: feed the DOM to ChatGPT or Claude.
  • Test: run the script locally before the real site.
  • Package: turn the useful bit into something repeatable.
Timing: 2 minutes. Live-along three: right click, save the page, paste a line into the console, watch the page change in front of the room. This is the heart of the talk. You are not asking the model to operate the system. You are asking it to help you reshape a page you already have. On a past project this exact move was how we did A and B testing, which is billable consultancy work, not a toy.

Make it stick

A script earns its keep when it comes back tomorrow.

Install A userscript manager

Tampermonkey, Violentmonkey, or Greasemonkey. They handle install, update, and the GM_* superpowers normal page code lacks.

Share Extension shaped

A console trick helps me. A packaged extension helps the colleague who just wants it to work.

Timing: 2 minutes. A userscript is JavaScript that runs on matching pages. A manager makes it repeatable. The honest gap: a console script is great for me and useless for my non technical colleague, who is not going to paste anything into anything. That gap is the reason the next rung exists.

Solve the general problem

I built a compiler, not a single extension.

The question What is the generic version?

Do not package one Vertec script. Build a tool that turns any userscript into a real extension.

UserScript-Compiler One script, three browsers

Polyfills GM_* methods, writes the manifest, outputs Chrome, Firefox, and Safari packages, plus a submission guide.

Timing: 2 minutes. This is the forward deployed instinct in miniature: turn a one off fix into reusable leverage. "One fix" becomes "a tool that makes fixes". Live-along five: paste the Vertec script into the compiler, download the unpacked extension, load it in developer mode. "Whose extension icon just appeared?" That applause is the point.

A harness, from day one

Load the saved Vertec DOM as a fixture. Drive it with Playwright. Let a sceptic run the same thing and see the same result.

Deep modules

Small interface, lots of messy Vertec hidden behind it. As Ousterhout intended.

Timing: 2 minutes. This is where the talk turns from vibes into engineering. Playwright drives a real browser, and Playwright MCP can hand an agent the accessibility tree instead of pixels, which is cheaper and more reliable. A harness is not ceremony. It lets a doubter reproduce the result.

The lever on agent output

Bad codebases make bad agents.

Deep module

Small interface, big implementation. Hide the Vertec mess behind one or two clean functions.

The deletion test

If removing a module makes the system simpler, it was never pulling its weight.

The dumb zone

Models get worse past roughly 100k tokens. A bigger context window just ships more confusion.

Structure is the lever. A better repo gives you a better agent, every single run.

Timing: 2 minutes. From Ousterhout's "A Philosophy of Software Design" by way of Matt Pocock. The single biggest influence on agent quality is how the code is organised. Keep the surface tiny, keep the implementation deep, and keep the working context small enough that the model stays sharp.

How I actually use agents

Steer it. Do not become the passenger.

Just talk to it Grill me first Subagents and /goals Issues as a queue Ralph loops Reasoning levels Local Ollama and Qwen

The trick is not knowing every command. It is knowing when the output smells wrong.

Timing: 3 minutes. The knowledge sharing slide. "Just talk to it" (Peter Steinberger): run several agents in a grid and develop intuition. "Grill me" (from Matt Pocock's skills): the agent interviews you with 40 to 80 questions until you share one mental model. Subagents and /goals in the Codex app for parallel work. GitHub Issues as an orchestration queue, with humans always reviewing the pull request. Ralph loops (Geoffrey Huntley): fresh context each pass, read plan, pick one task, implement, test, commit, repeat overnight. Reasoning levels: medium for most work, high for hard problems. And local models with Ollama and Qwen for client work where cloud AI is not allowed. A 7B or 9B model runs happily on a 16GB MacBook. If you ever run out of API usage, ChatGPT with connections can write the code and hand you a diff.

Make it responsible

Bypassing the UI is not the same as being safe.

Observed /uisync

The webapp traffic is SignalR shaped. There was no friendly POST called please-save-my-timesheet.

Auth Two gates

Zühlke access can launch Vertec. Vertec can still ask for its own login.

MCP checkSession first

The first useful tool says whether the agent is allowed to do anything at all.

Read Draft Validate Confirm Write Audit
Timing: 2 minutes. The API and MCP lesson without pretending we captured a neat production POST. Reverse engineering the network tab and doing a cross origin POST is a real option, and it is discovery work, not a spell. Copied browser cookies are not an auth model: they expire and it is unsupported. When you remove the UI's accidental friction, add intentional friction: read, draft, validate, confirm, write, audit.

Essential AI literacy

Learn to smell the slop.

The tells: "it's not X, it's Y", em dashes everywhere, ASCII arrows, neat lists of three, cards and gradient fog (Codex's signature look), image defects, and, at Zühlke, an umlaut someone clearly typed by hand. Output is raw material. Make it yours before it makes you look haunted.

Timing: 2 minutes. Teach this as a skill, because the real skill is judgement. Text tells: negative parallelism, em dash overkill, the rule of three, words like delve and seamless, confident paragraphs nobody asked for. Code tells: emojis in comments, step by step comment patterns, bloat. Be fair, an em dash alone proves nothing. Link it back to CDM: the loop only works if humans inspect the artefacts and improve them.

Know when to stop

Better is not always more AI.

Where slop is fine

Throwaway personal helpers and one off exploration. Vibe coding raises the floor.

Where it never is

Client work, billing, HR, anything a teammate maintains. Agentic engineering preserves the ceiling.

Beware the AI vampire

The trap is opportunity cost, not token cost. The limit that matters resets at sunrise, not midnight.

A multi-agent swarm to fill three timesheet rows is a microservice for a to-do list. Sometimes the answer is a one line script.

Timing: 2 minutes. Karpathy's framing: vibe coding raises the floor, agentic engineering preserves the ceiling. Decide by the blast radius. The AI vampire is the person who stays up because the usage limit resets at midnight, and pays for it with the far more expensive resource, their evening. Faster, clearer, or cheaper by hand? Do it by hand.
