Context window

Know what the model can see.

It can read the page you give it, the files you attach, and the tools you connect. It cannot magically know the rule your team agreed last Thursday.

Timing: 2 minutes. Teach this without making it grand. Context is files, screenshots, DOM, traces, tools, and rules. If the model cannot see the policy, it will guess. If the model cannot write through a supported API or browser action, it should draft and ask.
